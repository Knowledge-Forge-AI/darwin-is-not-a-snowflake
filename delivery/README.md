# Historical source fixtures

The browser ownership kits in this directory are retained to test the guarded
source contracts and delivery validation code. This public preview replaces
operator identifiers with examples. Historical identities, digests, patches and
readback records are not current qualification or activation authority.

Do not apply these historical patches to a live checkout, infer that a host was
qualified from a retained record, or use these files to select a deployment.
Current source selection and activation require fresh, separately reviewed
artifacts for the actual composition. Browser-role cutover remains held by the
source's mechanical gates.
