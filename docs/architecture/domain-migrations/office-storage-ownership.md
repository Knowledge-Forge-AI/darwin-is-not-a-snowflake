# Office and storage ownership continuation

The 2026-10-08 decision supersedes the former separate office/storage destination
plan in ADR 0002. No new destination repositories are planned for these domains.
A generic non-public storage/security owner receives personal cloud storage,
backup, encrypted transfer/restore, filesystem support and the complete Microsoft
Office provider including OneDrive. Microsoft Office remains one suite provider.
Its Defender shim declaration is retained; runtime use is a separate discovery
question and no decommissioning is part of this source increment.

Core retains separately packaged Teams, Zoom and Adobe Acrobat Reader and
manages LibreOffice, ONLYOFFICE Desktop Editors and Zettlr on the current host.
GrandPerspective is also a core diagnostic by ownership, but its existing 3.7.2
application remains externally installed and intentionally is NOT a core-managed
Homebrew cask or application claim. Other hosts receive no additive installs. Future web document
wrapper ownership stays in core without a new wrapper implementation here.
Unrelated desktop/MAS declarations and KeePassXC/native messaging remain core.

The matched source candidate removes storage/suite ownership from core and
retains the generic user-home helper and DINAS command namespace seam. Core's
existing Codex restore consumer retains the shared restore package export;
PostgreSQL tooling exposure stays because other uses are unresolved. Optional
rclone consumer closures pin their package and do not require the non-public
owner or a healthy backup to launch ordinary tools.

Remaining sequence: owner review and source acceptance, matched composition
selection, independent build/claim/config/command qualification, installed-app
ownership reconciliation, acquisition of missing requested core apps, then one
normal attended deployment. Preserve working suite apps, cloud folders and peer
browser configuration. No joint atomic commit, permanent broker or broad global
activation gate is required. Historical migration evidence remains historical.
A bounded 2026-10-11 inspection verified GrandPerspective 3.7.2 build 25 at
/Applications but found no Homebrew receipt, mas registration or Mac App Store
receipt. Installation provenance remains unknown. Preserve the existing bundle:
no cask force/adopt/reinstall, no App Store acquisition, no replacement or cleanup.
A separately approved migration can assign a provider in a later phase.
This external-install exception does not change its core diagnostic owner.
Do not install its cask over an existing unmanaged bundle without that preflight.
